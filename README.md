# Суфлёр для рилсов

Веб-приложение для Redmi Note 10S: крупный текст, плавная автопрокрутка и режим «По голосу», в котором текст двигается, пока вы читаете вслух.

## Что в папке

| Файл | Зачем |
|---|---|
| `index.html` | сам суфлёр |
| `manifest.webmanifest`, `sw.js`, `icon-192.png`, `icon-512.png` | чтобы суфлёр ставился как приложение с иконкой и работал без интернета |

## 1. Публикация (один раз, минут 10)

1. Зарегистрируйтесь на <https://github.com/signup>, это бесплатно. Имя пользователя станет частью адреса суфлёра.
2. Справа сверху нажмите **+** → **New repository**. Название: `prompter`, тип **Public**, затем **Create repository**.
3. На странице репозитория нажмите ссылку **uploading an existing file** и перетащите пять файлов: `index.html`, `manifest.webmanifest`, `sw.js`, `icon-192.png`, `icon-512.png`. Нажмите **Commit changes**.
4. Откройте **Settings** → **Pages** (меню слева). В поле **Source** выберите **Deploy from a branch**, ветку **main**, папку **/ (root)** и нажмите **Save**.
5. Через 1–2 минуты суфлёр откроется по адресу `https://ВАШЕ-ИМЯ.github.io/prompter/`.

Ваши тексты на GitHub не попадают: они хранятся только в телефоне.

## 2. Установка на Redmi

1. На Xiaomi сначала разрешите Chrome создавать иконки: **Настройки → Приложения → Chrome → Другие разрешения → Ярлыки на рабочем столе → Разрешить**.
2. Откройте адрес суфлёра в **Chrome**.
3. Нажмите **⋮** (три точки) → **Добавить на главный экран** → **Установить**.
4. Открывайте суфлёр с иконки на главном экране. Так он запускается на весь экран и работает без интернета (кроме режима «По голосу»).

## 3. Как снимать

- Поставьте Redmi на держатель вплотную под iPhone (или над ним), примерно в 50 см от лица.
- Ползунок **«Строка чтения»** задаёт, где на экране читать. Ставьте её ближе к краю, который ближе к камере iPhone. Если Redmi стоит под iPhone, подойдёт 15–25%: так взгляд почти не уходит от объектива.
- Яркость Redmi лучше поднять повыше.
- Порядок: включите запись на iPhone → нажмите **«Начать»** на Redmi → отсчёт 3-2-1 → читайте строку напротив жёлтых стрелок.
- **Касание экрана** ставит паузу или продолжает чтение. **Ведите пальцем по тексту**, чтобы перемотать. Кнопки **− / +** внизу меняют скорость прямо на ходу.
- В паузе можно сменить режим, скорость и размер шрифта или начать сначала.

**Скорость.** 130 слов в минуту — средний темп, для бодрых рилсов подойдёт 150–170. Под текстом в редакторе видно, сколько примерно продлится ролик.

## 4. Режим «По голосу»

- Нужен интернет (речь распознаёт Google) и разрешение на микрофон. Chrome спросит его при первом запуске.
- Пока вы молчите, текст стоит. Когда читаете, едет дальше, а прочитанные слова становятся серыми. Если вы отвлеклись от текста, просто продолжайте читать: суфлёр сам найдёт место. Текст можно подвинуть и пальцем.
- На некоторых Android при включении распознавания звучит короткий сигнал. Чтобы его не записал iPhone, убавьте громкость Redmi до нуля.
- Если распознавание сбоит, поставьте паузу и переключитесь на «Авто».

## 5. Как добавить текст

- Скопируйте текст (из Заметок, Telegram, Google Документов) и нажмите в суфлёре **«Вставить»**. Можно и иначе: долго нажмите на поле с текстом → «Вставить».
- После установки иконки текст можно отправить прямо из другого приложения: выделите его → **«Поделиться»** → **«Суфлёр»**. Он появится как новый текст.
- Тексты сохраняются сами. Переключаться между ними можно в выпадающем списке вверху.

## Если что-то не так

- **Гаснет экран.** Суфлёр сам не даёт экрану погаснуть. Если всё же гаснет: Настройки → Экран → Спящий режим → 10 минут.
- **Обновление.** Загрузите новые файлы в тот же репозиторий (**Add file → Upload files**). Телефон подхватит новую версию со второго запуска.
- **Bluetooth-пульт** (если появится): пробел или Enter ставит паузу, ↑/↓ меняют скорость, ←/→ перематывают текст.
